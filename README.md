# CS-340-Client-Server-Development

Journal Reflection

How do you write programs that are maintainable, readable, and adaptable?

When writing programs, I try to keep my code organized so that it is easier to understand, maintain, and make changes when needed. One example of this was creating the CRUD Python module in Project One and then reusing it in Project Two. Instead of writing all the MongoDB operations directly into my dashboard, I used the CRUD module to handle the database connection and queries separately. This allowed me to focus on developing the dashboard features, including the rescue filters, interactive table, pie chart, and map.

Another advantage was that I could reuse the same module without rewriting the database operations. In the future, I could use a similar CRUD module in other applications that need to interact with a MongoDB database.

How do you approach a problem as a computer scientist?

When approaching a problem, I try to understand the requirements first and then break the project into smaller tasks. For the Grazioso Salvare project, I started by connecting my CRUD Python module to MongoDB and retrieving the animal shelter records. After that, I worked on the rescue filters, interactive table, pie chart, and map. I tested each feature as I developed it to make sure everything worked correctly.

This project was different from some of my previous assignments because I had to connect multiple components into one application rather than focusing on a single program. Based on my instructor's feedback, I also learned that I could improve my queries by accounting for mixed-breed variations and make my dashboard more reliable by adding additional coordinate validation.

In future projects, I would continue breaking down requirements, testing each component, and considering different situations that could affect how the application works.

What do computer scientists do, and why does it matter?

Computer scientists use programming and problem-solving skills to develop solutions that help people and organizations work more efficiently. Their work can involve developing software, managing databases, analyzing information, and improving existing systems.

In the Grazioso Salvare project, I developed a dashboard that allows users to search animal shelter records based on specific rescue training requirements. Instead of manually searching through thousands of records, users can select a rescue category and view matching animals through an interactive table, pie chart, and map.

This could help Grazioso Salvare identify animals that meet their training requirements more efficiently. Working on this project helped me understand how computer science can be used to solve real-world problems and why it is important to develop applications that are reliable and easy to use.
